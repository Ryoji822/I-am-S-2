# 単独で読める日報と定期レビューを生成する

検証済み記録と保存済み企業・市場の全本文をプログラムで表示します。別のモデルは起動しません。

今日採用した根拠、今回更新した節、5社の継続状態、市場全体、5つのシナリオ、仮説の見直し、期間別の予測実績、危険と不足の順に表示します。過去の基準日・後日確認の注記を残し、日付だけを今日へ貼り替えません。失敗時に薄い正式日報で上書きしません。新着のない日や部分収集日も既知の会社情報を維持します。

根拠と次の確認を近くに置きます。週次は予測と実績、月次は社会・会社・個人、四半期は因果関係を確認します。採点0件は未評価です。保存前の構造・出典・時刻・範囲の検証は文章の正しさを自動的に保証しないため、反証段階で原資料と本文を照合します。
