# 企業情報と市場資料を蓄積する

独立したモデルは起動しません。主分析のdossier_sectionを反証・裁定・スキーマ・出典・時刻・更新系列の検証後に保存し、同じ確定スナップショットから日報とStaticを生成します。

初期本文はconfig/dossiersの7冊です。企業5社の製品・顧客・事業規模・販路・能力と制約・経緯、および市場・シナリオを保持します。新情報がない日、部分収集日は本文を維持します。根拠のない更新は保存しません。企業の全体像を新着見出しや仮説の所感だけへ縮めません。

accepted-plan.jsonは採用された全本文も保存するため、再実行時はモデルを呼ばず同じ内容を復元できます。過去Informationを変更する処理ではありません。shadowでは日報・Staticともstate/shadow配下へ出力します。
