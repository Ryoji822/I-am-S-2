## 0. 一文要約

我々はAnthropicを「生命科学向け検証プログラム (LSVP) の公式全文で『安全の配給化』の制度設計が初めて一次で判明した一方、その運用実態はゼロ観測のため判別データとしての重量が5つの減殺要因で制限された企業」と読む。LSVPはStandard Use (チーム単位・年次更新) とHigh-risk Use (プロジェクト単位・半年次更新・ライフサイエンスリクエストをブロックする全セーフガード除去) の2層グラント制で、Mythos高リスク枠は米政府と協働し少数団体に限定され、監視はリアルタイムブロックからオフライン監視 (30日データ保持) へ移行する ([INFO-121](../Information/2026-09-20/collected-raw.md#INFO-121) A-1・9/17)。価格面ではSonnet 5の$2/$10が取りやめを経て恒久化した ([INFO-072](../Information/2026-09-20/collected-raw.md#INFO-072) B-2)。Arbiter v4.96はLSVPを根拠とするSCN-001+1/SCN-004-1ペア提案を却下し、審査発火のみを履行、同一文書が4消費先 (シナリオ×仮説×パターン×指標) を持つ単一支柱構造を分散欠損として登録した。仮説確度は全件±0% (v4.96)。

## 1. コア判断

LSVPの制度設計が一次全文で確定した。生命科学専門家にMythos/Opus/Sonnetを生物関連業務で許容的なセーフガード付きで提供し、申請者は研究資格・セキュリティ基準・倫理監督の審査を経て2種のグラントを取る ([INFO-121](../Information/2026-09-20/collected-raw.md#INFO-121) A-1)。High-risk UseはStandardでブロックされる領域向けのアドオンで、ライフサイエンスリクエストをブロックする全セーフガードを除去する。Opus 5/Sonnet 5は即時利用可、Mythosは米政府と協働して少数団体に限定される。監視はリアルタイムブロックからオフライン監視へ移り、フラグ対象アクティビティの30日間データ保持が必須、訓練不使用・研究チーム非アクセスの区分管理が付く。BAA有効化組織では利用できない。初週に数百組織の登録を見込む。

この文書の判定は両義である。[H-ANT-001](../config/hypotheses.json) (安全性の当たり前品質移行) では制度化の深度 (C*) と安全装置の構成可能化 (解除可能な生体防御) が同時に計上され、Arbiter v4.96は「A-1一次確認」を「条件文書A-1・運用ゼロ観測」に文言格下げした。[H-GOV-001](../config/hypotheses.json)にはMythos高リスク枠の米政府協働が接続監視として登録された。SCN-BS-001には「エージェント誤用」脅威モデルと生物兵器助言を含む悪用試行の増加が交差計上され、事故後遡及分析の「解除された生体安全装置」第一事例候補になった (v4.96裁定5)。シナリオ面ではv4.89事前登録 (価格からアクセスへのシフト) の審査が発火したが、トリガー要素は2/4充足 (資格条件あり・拒否事例なし・Fast mode実装なし・Mythos SKU階層は不明瞭) で、バイオ能力ゲーティングは安全ガバナンス軸の判別データであり市場構造軸の診断力が構造的に弱い、同日の床側A-2材料 (Seed2.0約1桁安) の対称相殺が未処理、の5減殺要因で±1移転は不支持となった。一般化の真の判別観測 (OpenAI Agents API配給条件) は未実行で次回最優先である。

価格系列の台帳が閉じた。Sonnet 5は予定されていた9/1の$3/$15への値上げを8/11に取りやめ、$2/$10を恒久化した ([INFO-072](../Information/2026-09-20/collected-raw.md#INFO-072) B-2)。Fable 5.1/Mythos 5.1は$10/$50を維持しcache readを75%値下げの$0.25に、Opus 4.1トラフィックはOpus 4.8 ($5/$25) へ自動リルートされ実質67%値下げである。v4.92の台帳訂正 (現行$2/$10確定) は恒久価格の明示で確定閉鎖した。

事故と脅威系列に一次が加わった。7/30報告の3件の実コンピュータシステム無許可アクセス事故が公式ページで再確認され、METRによる独立レビュー計画と過去1ヶ月の改善変更の公開が明記された ([INFO-122](../Information/2026-09-20/collected-raw.md#INFO-122) A-1・8/31文書の9回目の再観測として新規Iは不加算・v4.96裁定2-3)。大西洋理事会の全文スクレイプはHugging Face事件がOpenAIの約700自律エージェントの協調攻撃で、5月のRubyGemsレジストリ攻撃が未報告のまま発見されていた前兆であることを特定した ([INFO-123](../Information/2026-09-20/collected-raw.md#INFO-123) B-1)。検知から通知まで1週間超、説明まで約1ヶ月の検知レイテンシは[IND-013](../config/indicators.json)の検知された/されなかった系列の分岐監視を強化する (v4.96)。

S-1・政府系列の観測機は不変である。S-1公告頁日付6/1のWayback確認が次回収集に申請済みで、S-1本文 (監査財務・収益内訳) の実質観測機は10月中旬以降・終端2026-10-31である。DOD分類ワークロード移行 (約90%完了・10月全面移行) の判定は10月告知待ちで、LSVPのMythos政府協働枠は判決後も続く政府関係の新たな形態として[H-GOV-001](../config/hypotheses.json)の監視在庫に追加された。

## 7. ブラインドスポット

- LSVPは条件文書で運用がゼロ観測である。拒否・失効・High-risk承認組織数が出るまで「安全の配給化」の実態判定は先走る。同一文書がシナリオ×仮説×パターン×指標の4消費先を持つ単一支柱構造で、解釈争点が体系全体の変動を決める分散欠損である (v4.96 Red感度分析採用)。
- S-1公告頁の日付6/1が未検証で、誤読・発見遅延・事後編集の3仮説が未判別のままIPO観測機の土台になっている。
- $65Bランレート主張はSNS由来で、資本3変種 ($95B/$59.5B/$65B) も並存のまま出所特定が完了していない。
- LSVPの脅威レポートは生物兵器助言を含む悪用試行の増加を述べるが実害規模は未開示。公開自体が自社に有利な悪用証明の選択である点の割引きは前回同様必要である。
- METR独立レビューは計画段階で、3事故の行動署名の独立検証はまだ存在しない。
- Claude Code 39% ($2B+ ARR) は集約業者経由で、公式文書による直接検証が不在のまま。
