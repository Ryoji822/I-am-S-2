# AI市場レポートの設計

AI企業や市場を追う読者が、朝に日報を開き、前回から判断を変える材料が出たかを確かめられるようにする。重要な変化、根拠の強さ、次に見る資料が最初の画面に収まる分量を目安とする。

| 開く資料 | 最初に分かること | 詳しく調べるとき |
|---|---|---|
| 日報 | 今回分かったことを最大3件。発表元の説明や資料の不足は、該当する記述のそばに置く。 | 当日の詳細記録で全文、出典、確認できなかった項目を読む。 |
| 企業・市場資料 | 資料ごとの最終確認日と、どの節をいつ見直したか。 | 節の本文から過去の調査や出典を確認する。 |
| 定期レビュー | 期間中にどの論点を見直したか。判断を改めた記録と採点済みの件数。 | 日報と予測ごとの実績・採点に進む。 |

日報の各項目は「分かったこと」「前回の確認」「次に確かめること」の順で読む。同じ論点の記録があればその日に戻れるようにする。新しい根拠がない日は、採用なしと最初に表示する。資料を取得できなかった場合は確認の範囲も表示する。

## 公開前に確かめること

- 日報の最初の項目だけで、誰に何が起きたかと、どこまで確認できたかが分かる。
- 今回の採用記録と過去の調査を区別し、同じ公式フィードからの複数記事は出所1系統と数える。
- 同じ論点の前回記録をたどれる。日報を短くしても、採用した資料、根拠の不足、企業資料の本文を詳細から読める。

設計には `reframing-storytelling` の経営向けメモ、調査の再構成、日本語の段落設計を適用した。本文の推敲と意味の照合には `explain-before-shorten` を使う。
