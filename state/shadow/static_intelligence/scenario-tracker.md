# 5つの未来：現在の証拠から、仕事・利益・生活の分岐を読む

基準日：2026年9月21日。9月22日に再構成。これは9月21日時点に発行した確率予測ではなく、公表済み資料を用いた後日の評価です。5つの未来は同時に進み得るため、確率を合計100%にしません。

## 現在の位置

**AIを使う入口と実行機能は拡大しています。一方、その利益が雇用・所得へ広く届く経路は、まだ一方向に決まっていません。** 供給企業の売上・投資、製品の価格や公開コードは観測できます。労働面では既存の利用者の改善と、若年採用への圧力が併存する材料があります。給付や所有構造の転換は、今回の資料だけでは実施の広がりを確認できません。

| 世界像 | 現在の証拠が支える範囲 | 判断を超えてはいけない範囲 |
|---|---|---|
| W1 人とAIで仕事の需要が広がる | 作業を支援する製品、利用者の改善、企業向け需要 | 全国の採用・実質所得が一律に増えるとは未確認 |
| W2 AIや顧客接点の所有者に利益が集中する | 大規模投資、仕事場とモデルの統合、条件を決める力 | 高売上や高評価額を、そのまま高利益・独占としない |
| W3 知的作業が安く広く使える | 低価格のモデル、公開された実行コード、制作機能の普及 | 実務の総費用や小企業の利益改善は別途必要 |
| W4 仕事以外の仕組みが生活を支える | 雇用移行を支える必要性を示す材料 | 支援の必要性は、給付が実施・利用された証拠ではない |
| W5 所有と分配のルールが変わる | 監査・公共関与の議論と制度化 | 安全規制や企業買収を、公共・共同所有の実現に数えない |

数値の確率を置いていないのは判断を放棄するためではありません。どの段階まで証拠があるかを明示し、後の実績で変えられる判断にするためです。

## W1：補完から、新しい需要と仕事へ

この経路は、AIが作業の一部を短縮し、人が顧客理解・責任・判断を担い、価格低下や新しい提供物で需要が増える場合に成立します。需要の増え方が必要な労働時間の減り方を上回れば、雇用も増え得ます。単に同じ納品物を少人数で作るだけなら、企業の利益が増えてもこの経路の後半は成立しません。

支持材料には、企業の仕事を実行する Agents API や Claude、Google の法人利用があります。日本のJILPTの2024年労働者調査も、AI利用者の仕事の質の改善と訓練・対話の関係を報告しています。[Agents API](https://openai.com/index/introducing-the-agents-api/)、[Google決算説明](https://blog.google/company-news/inside-google/message-ceo/alphabet-earnings-q2-2026/)、[JILPT](https://www.jil.go.jp/institute/research/2025/256.html)。

逆方向の材料は、米国ADPを用いたStanfordの研究です。AIへの露出が高い職種の若年層の雇用は、低露出の同年代を基準とする比較で弱く、主に採用に差が出ています。これは全雇用の消滅でも日本の因果効果でもありませんが、「生産性向上なら自動的に全員の雇用も改善する」という説明を弱めます。[8月改訂の研究](https://digitaleconomy.stanford.edu/publication/canaries-in-the-coal-mine-six-facts-about-the-recent-employment-effects-of-artificial-intelligence/)。

短期は完成品質と確認時間、中期は新しい受注と新人採用、長期は移行後所得と実質賃金が分岐です。人の役割が高度化したという企業説明だけで、入口の職が減った問題を解決済みにしません。

## W2：供給と顧客接点を持つ企業へ利益が集まる

AIを実行するための設備と、顧客が普段使う画面の両方に規模の利点があれば、利用が増えるほど一部の供給者に交渉力が集まります。モデルの単価が下がっても、運用・管理・配信をまとめて売る会社が利益を取ることは可能です。

Google の検索・Workspace・Cloud、OpenAI の ChatGPT・Codex、ByteDance の制作・配信の接点は、この経路を考える材料です。OpenAI と Anthropic の大型調達、Google の設備投資計画は、参入に必要な資本が大きいことも示します。[OpenAI](https://openai.com/index/accelerating-the-next-phase-ai/)、[Anthropic](https://www.anthropic.com/news/series-h)、[Google投資家説明](https://blog.google/alphabet/investor-presentation-june-2026/)、[ByteDance](https://www.bytedance.com/)。

ただし資本集中と利益集中は同じではありません。SpaceX のAI部門の営業損失は投資回収の難しさを示し、Grok Build の公開や Agents API の実行先の選択肢は、一部の移行を容易にする方向の材料です。[SpaceX目論見書](https://content.spacex.com/cms-assets/FINAL_Documents%20and%20Updates/SpaceX%20-%20EU%20Prospectus%20%28Approved%20by%20Bafin%29%20-%20June%205%2C%202026.pdf)、[Build公開](https://x.ai/news/grok-build-open-source)、[Agents API](https://openai.com/index/introducing-the-agents-api/)。

このシナリオが強まるのは、利用企業が値上げ・条件変更に直面しても移行できず、供給者の利益率と顧客維持が同時に上がる場合です。逆に、同品質の代替へ短期間で移れ、新規の提供企業にも利益が残れば弱まります。モデルを替える操作だけでなく、データ・接続・監督の移行費を見ます。

## W3：知的作業へのアクセスが広がる

安価なモデルと再利用できる実行ソフトがあれば、以前は専門家や大きな開発予算が必要だった作業に小企業や個人が参加できます。Sonnet 5 の価格維持、Grok 4.6 の価格、Build のコード公開、Seedance 2.5 の制作機能は、この経路の入口を支えます。[Sonnet](https://www.anthropic.com/news/claude-sonnet-5)、[Grok](https://x.ai/news/grok-4-6)、[Seedance 2.5](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)。

制約は、安い利用料でも品質確認、顧客獲得、権利処理、運用の費用が残ることです。動画を作れることと広告成果が得られること、アプリを作れることと継続して保守・販売できることは別です。アクセスが広がるほど成果物が増え、販売価格が下がる可能性もあります。

短期は同じ仕事を同じ品質で終える費用、中期は小規模事業者の参入・継続・利益、長期は教育や専門サービスへのアクセスを見ます。W2とW3は両立し得ます。利用者の入口が安くなっても、計算資源や集客の持ち主に利益が集まる場合があるためです。

## W4：仕事以外の所得とサービスが生活を支える

AIで一部の労働需要が減り、新しい職への移行が追いつかない場合、給付、保険、公共サービス、資産所得が生活を支える割合を増す経路です。採用の入口の縮小は検討の理由になりますが、米国の研究だけで日本にこの制度移行が必要・実現済みと断定できません。

今回確認した資料では、AIによる恒常的な所得減を補う新しい全国制度の支給額・受給者・生活改善を比較可能な形で把握していません。ここは「制度がない」という断定ではなく、実施結果を収集できていないという判断です。AI企業の成長や安全規制を、給付実績の代用品にはしません。

短期は失職と再就職の間の所得、中期は申請条件・支給開始・利用率・財源、長期は実質的な生活水準を見ます。再就職後の賃金が回復するなら労働を中心とした経路が強まり、給付が実際に不足を埋めればW4の根拠が増えます。政策の発表と利用できる制度を分けることが読者の判断に直結します。

## W5：所有と分配のルールそのものが変わる

この経路には、計算資源・モデル・データ・利益への権利について、公共や共同の所有・決定権が制度として広がることが必要です。国が監督するだけで所有が変わったことにはならず、xAI が SpaceX に入る企業買収も公共化とは異なります。[xAIの買収発表](https://x.ai/news/xai-joins-spacex)。

カリフォルニアの9月18日の行政命令は、独立した検証や監査を強める方向の材料です。しかし、これは安全を管理する制度であり、計算資源や会社の所有権を公共に移す決定ではありません。[州政府説明](https://www.gov.ca.gov/2026/09/18/governor-newsom-issues-executive-order-to-accelerate-independent-oversight-and-advance-the-creation-of-an-ai-kill-switch/)。

3〜10年の探索では、法的な権利の変更、持続する財源、利用者が意思決定に参加できるか、供給と分配が継続するかを追います。公開コードの存在も、会社の利益への所有権を利用者へ与えるものとは限りません。現在の資料はW5の実現を強く支持する段階にはありません。

## 読者の判断へどう結び付けるか

会社は、AIが安くなることと、自社に利益が残ることを別に検証する必要があります。顧客との関係、業務知識、品質の責任を保持しつつ、モデルや実行環境を替えられる構成の価値が高まります。個人には、作業速度だけでなく、顧客の問題を定め、結果を検証し、別の職や取引先へ移れる能力が重要になるという含意があります。これは現在の構造からの推論であり、本人の所得を測った結論ではありません。

社会については、既存社員の効率化と新人の経験形成を一緒に評価する必要があります。入口の業務を自動化しても育成の代替経路がなければ、将来の熟練者を作る仕組みが弱くなる可能性があります。訓練の実施だけでなく、修了後の採用・賃金まで追います。
