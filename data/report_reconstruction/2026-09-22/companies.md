## OpenAI：個人利用を企業の仕事へつなぐ

OpenAI の事業は、個人・法人が直接使う ChatGPT、開発者の作業を進める Codex、企業が自社製品へ組み込む API を中心とします。3月31日の会社説明では週間利用者9億人超、有料契約5,000万人超、月間売上20億ドル、企業向けは売上の40%超でした。これは3月の自社公表値で、9月の監査済み決算ではありません。[会社説明](https://openai.com/index/accelerating-the-next-phase-ai/)

9月3日発表の GPT-6 Astra は、開発・専門業務・コンピューター操作の能力を重視しています。9月10日の Agents API は、Codex の実行機構を使い、セッション、道具、複数エージェントを管理する公開ベータです。自社・提携先の実行環境を選べるため、モデルの回答だけでなく仕事を動かす仕組みを購入する構成になっています。[Astra](https://openai.com/index/gpt-6-astra/)、[Agents API](https://openai.com/index/introducing-the-agents-api/)

3月に公表した調達はコミット済み資本1,220億ドル、調達後評価額8,520億ドル。Microsoft、Oracle、AWSなど複数のクラウド・計算資源の供給元を組み合わせる方針です。調達は将来の能力拡張を支えますが、売上や利益とは異なります。既存の消費者基盤から企業の継続収益へ広げ、利用の増加で供給費用を回収できるかが争点です。[資金と供給の説明](https://openai.com/index/accelerating-the-next-phase-ai/)

能力の高い実行には監督も必要です。Astra の安全説明は高度なサイバー能力と監視の課題を扱っています。使える実行環境が増えたことから、モデル、会話履歴、認証、評価を含む全システムが簡単に他社へ移せるとは結論できません。[安全説明](https://openai.com/index/safety-overview-gpt-6-astra/)

評価：企業の仕事場へ販売を広げる製品と規模がある一方、顧客側の総費用と利益、OpenAI自身の利益率は別の測定が必要です。短期は確認・再実行を含む完成費用と移行時間、中期は本番利用と契約更新、長期は仕事場を持つことが持続的な利益につながるかを見ます。9月22日に確認した更新型の料金表は、この過去日報の価格実績に使っていません。

## Anthropic：能力、業務への接続、利用条件を一緒に提供する

Anthropic は Claude、Claude Code、Cowork、API を持ち、AWS・Google Cloud・Microsoft Azureでも提供します。企業が既存の調達・請求環境を使える販路と、直接契約の両方を持つ構造です。5月28日の会社発表は、年換算売上ペース470億ドル、Series H調達650億ドル（既公表のコミット150億ドルを含む）、調達後評価額9,650億ドルを示しています。年換算値は通年の売上実績・利益ではありません。[会社と供給の説明](https://www.anthropic.com/news/series-h)

Sonnet 5 は6月30日、Opus 5 は7月24日発表。日常の仕事と難しい仕事を費用に応じて使い分ける構成です。Sonnet 5 の価格は入力100万トークン2ドル、出力10ドルで、8月10日の公式訂正により恒久化しました。9月から3ドル・15ドルへ戻す旧予定は失効しています。トークンの区切り方も変わるため、価格低下率を仕事の費用削減率へ直接変換できません。[Sonnet 5](https://www.anthropic.com/news/claude-sonnet-5)、[Opus 5](https://www.anthropic.com/news/claude-opus-5)

供給面ではAmazon、Google／Broadcomとの大規模契約、SpaceXのColossusへのアクセスを説明しています。6月1日には非公開S-1草案提出を発表しましたが、上場日が決まったという意味ではありません。7月9日のUST提携は製造等の業務へ接続し、2万人の技術者等を訓練する計画です。計画人数と成果を出した人数は区別します。[資金・供給](https://www.anthropic.com/news/series-h)、[S-1](https://www.anthropic.com/news/confidential-draft-s1-sec)、[UST](https://www.anthropic.com/news/ust-claude)

6月18日の Project Fetch は限られたロボット関連課題での高速化を示しますが、研究者による接続・承認等を含み、仕事全体の無人化を証明しません。8月31日の安全対応は7〜8月の評価環境での事案への対策で、全顧客向けサービスが同日に停止したという話ではありません。[Fetch](https://www.anthropic.com/news/project-fetch-phase-two)、[安全対応](https://www.anthropic.com/news/improving-alignment-security-efforts)

評価：専門業務へ入り込む能力と販路がある一方、監督・安全・供給の条件も売る製品の一部になっています。短期はモデル間の完成費用と提供面の差、中期は契約更新と供給の稼働、長期は顧客の生産性とAnthropicの採算を一緒に確認します。安全を重視する説明だけでは、顧客が他社より選ぶ理由になったことまでは分かりません。

## Google／DeepMind：検索・業務ソフト・クラウドの既存基盤にAIを配る

Google は検索・YouTubeの広告、Workspace、Google Cloud、Geminiの直接利用にAIを組み込んでいます。モデルだけを売る会社との違いは、顧客との接点、法人販売、TPUを含む計算資源を同時に持つことです。AI機能が既存事業を強くする収入と、AIそのものを売る収入を分けて読む必要があります。[7月22日の決算説明](https://blog.google/company-news/inside-google/message-ceo/alphabet-earnings-q2-2026/)

同説明は、Alphabet全体の売上成長率24%、Search and Other17%、YouTube Ads13%、Cloud82%を示しています。Cloud受注残は5,140億ドルですが、その四半期の売上ではありません。Geminiアプリ月間9.5億人、Antigravity週間240万人超、Gemini EnterpriseはFortune 100の約90%が利用という公表もあります。人数、企業数、処理量は異なる母集団です。[決算説明の各指標](https://blog.google/company-news/inside-google/message-ceo/alphabet-earnings-q2-2026/)

6月3日の投資家説明は第1四半期Cloud売上約200億ドル、営業利益約70億ドル、利益率約33%、2026年設備投資1,800〜1,900億ドルの見込みを示しました。対象期間と公表時点を維持し、9月の実績として扱いません。Cloudには他社モデル用計算資源やデータ等も含むので、成長率をGemini単独のシェア増へ変換できません。[投資家説明](https://blog.google/alphabet/investor-presentation-june-2026/)

企業にとっての入口は、従業員がデータを検索・利用するGemini Enterprise、開発者が使うAPIやAntigravity、モデルを動かすCloudなどです。既存の情報管理と調達を使える利点がある反面、個人アプリとAPI、法人契約で機能・権限・提供条件が一致するとは限りません。[企業向け基盤の説明](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/gemini-enterprise-sundar-pichai/)

評価：既存事業とAIの供給網を組み合わせる強みは確認できます。企業採用の情報が存在しないという旧整理は不適切です。一方、Gemini単独の利益、導入企業の成果、データと監督手順を他社へ移す費用は別途必要です。短期は仕事の総費用と管理条件、中期は継続利用と投資の回収、長期は品質を保った費用改善が既存事業にも利益を残すかを確認します。

## xAI／SpaceXAI：Xの接点と計算資源から、開発と業務へ広げる

xAI はGrok、Grok Build、API、Colossusの計算基盤を持ち、2月2日にSpaceXによる買収を公式発表しました。買収の成立は確認できますが、事業・組織の統合完了とは異なります。AI部門の損益にはXの広告・購読等も含まれ、Grok単独の採算ではありません。[買収発表](https://x.ai/news/xai-joins-spacex)、[6月5日目論見書](https://content.spacex.com/cms-assets/FINAL_Documents%20and%20Updates/SpaceX%20-%20EU%20Prospectus%20%28Approved%20by%20Bafin%29%20-%20June%205%2C%202026.pdf)

8月12日発表のGrok 4.6は、長い開発作業や知識業務を対象とし、入力100万トークン2ドル・出力6ドルから、Fast版は2倍と説明しました。Build、Cursor、API、OpenRouter等の経路があり、自社の画面以外でもモデルを供給します。8月19日にはBuildをWeb・モバイルの全プランへ拡大し、作ったアプリの公開・共有につなげています。[Grok 4.6](https://x.ai/news/grok-4-6)、[Buildの提供](https://x.ai/news/grok-build-for-everyone)

7月15日に公開したBuildのコードは、モデルを動かす実行側の仕組みです。モデルの重みの公開ではなく、公開版とホスト型サービスを同条件で再現できる保証でもありません。ローカルの推論先へ向ける選択肢は移行を考える材料になります。[公開対象](https://x.ai/news/grok-build-open-source)

1月6日のSeries Eは200億ドル。会社は2025年末Colossus I・IIの能力を100万H100相当超と説明しました。換算した能力と同一GPUの実数は区別します。SpaceXの目論見書ではAI部門の営業損失は2025年63.55億ドル、2026年1〜3月24.69億ドルです。資源の規模が大きくても、回収できる利用と売上が必要です。[調達](https://x.ai/news/series-e)、[目論見書 §5.4.4.3](https://content.spacex.com/cms-assets/FINAL_Documents%20and%20Updates/SpaceX%20-%20EU%20Prospectus%20%28Approved%20by%20Bafin%29%20-%20June%205%2C%202026.pdf)

評価：低めのモデル価格、Xや外部開発ツール、公開ソフトを組み合わせて利用を広げる方向です。短期はレビュー込みの完成費用、中期はXを使わない企業の継続利用とAI部門の損益、長期は設備・接点の組み合わせが持続的な利益になるかを見ます。現時点で確認した4.6の仕様を、将来も最新であるという意味では使いません。

## ByteDance：制作・配信の接点と、法人向け供給を並行して持つ

ByteDance のAI事業は、Doubao、TRAE、Seed系モデル、火山引擎、動画・画像の制作にまたがります。既存のコンテンツ・制作・商取引の接点へ研究成果を配る経路と、企業へAPI等を提供する経路を持ちます。消費者の人数と法人の利益を同じ指標にしないことが重要です。[Seed2.0の展開先](https://seed.bytedance.com/en/blog/seed-2-0-official-launch)

Seed2.0は2月14日の発表で、9月の新モデルではありません。6月23日に発表されたSeed2.1は、複数の道具を使う業務や要件から実装・検証までの開発、画像・動画の理解を重視し、Doubaoと火山引擎での提供を説明しています。2.0の「上位モデルより一桁低い価格」という会社比較を、9月の最新モデル同士の実測へ持ち越せません。[Seed2.1](https://seed.bytedance.com/en/blog/seed2-1-officially-released-advancing-ai-productivity)、[2.0発表時の比較](https://seed.bytedance.com/en/blog/seed-2-0-official-launch)

Seedanceも2月12日の2.0に続いて、7月31日に2.5が発表済みです。2.5は最大30秒、画像30枚・動画10本・音声10本までの参照、位置を指定した編集等を説明しています。発売時のアプリ提供と、BytePlus ModelArk APIの提供予定を分けており、この資料だけで海外APIの稼働開始を断定しません。[Seedance 2.5](https://seed.bytedance.com/en/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)

9月4日にはReutersが約30行から296億ドルの融資を報道しました。関係者による条件説明は、無担保、当初3年と2年の延長選択肢、中国外の案件向けで、署名は記事時点で今後の予定でした。契約原文で検証した確定値と区別します。[Reuters配信記事](https://uk.marketscreener.com/news/bytedance-secures-29-6-billion-loan-in-ai-push-sources-say-ce785bdad189f22c)

評価：低費用の供給と、制作工程へ近い機能を広げる方向です。ただし権利処理、納品の修正、日本で契約できる提供面、顧客を獲得する費用が残ります。2.0の公式説明も実在人物の参照に本人確認・許諾等を求めています。[参照素材の条件](https://seed.bytedance.com/en/blog/seedance-2-0-official-launch)。短期は承認される成果物当たり費用、中期は消費者課金・法人利用の継続、長期は中国外でも制作・配信の接点が収益に結び付くかを見ます。異なる期間・定義の利用者推計から採算を算出しません。
